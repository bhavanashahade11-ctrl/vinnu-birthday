VINNU BEAUTIFUL BIRTHDAY WEBSITE

Files:
- index.html
- style.css
- script.js
- images/photo1.jpg ... photo7.jpg

To view:
1. Open this folder in VS Code.
2. Right-click index.html.
3. Choose Open with Live Server (or double-click index.html).

To publish:
Upload the complete folder to GitHub. Keep the images folder and all files together.
Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > / (root).

The website has:
- Cinematic birthday hero
- Photo-frame intro
- Memory gallery
- Love-story section
- Reasons section
- Letter section
- Final surprise button
- Floating hearts
- Light/dark theme
- Mobile responsive design
